An entry for the [make.fun](https://make.fun) competition `news-image-20261124`: one image summing up the world's news of Tuesday 24 November 2026, in the style of a dense newspaper front page — 31 stories, 13 main cards with CONFIRMED / OFFICIAL / REPORTED labels, a UTC timeline, a numbers strip, a world map and a date check.

## How it works

`main.ts` (Node 22, standard library only) copies the pre-rendered `entry.png` in this repository to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`), byte for byte.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
